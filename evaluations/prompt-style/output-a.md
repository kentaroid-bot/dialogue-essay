# 効率化で、対話の時間をつくる

本稿は青木とAIの対話をもとに、青木の着想をAIが整理し、後段でCodexが検討したものである。

## 青木の着想

青木は、図書館でAIが本の候補を用意すれば、司書が来館者と話す時間を増やせると考える。効率化の目的は、対話を増やすことにある。過去の貸出履歴だけでは推薦が似通う可能性があり、今の気分を聞き取る役割を司書に残したいという。

対話中、AIが会話の代替を提案すると、青木は目的とのずれを指摘した。AIの候補を司書が会話から選び直す案を受け、さらに対話時間を先に確保する必要性へ考えを進めた。空いた時間が別の業務に使われることも考えた、未実施のアイデアである。

## Codexの検討

私は、時間短縮と対話の充実を別の成果として扱う点を支持する。AIによる選書支援が速くても、業務の割り当てによっては来館者と話す時間は増えない。対話時間の確保を運用に組み込むことが、この着想を試す条件となる。

小さく試すなら、候補作成にかかる時間と、実際の対話時間を記録したい。来館者が選んだ本への納得感も尋ねれば、速さと交流の質を併せて評価できる。これらは今回、Codexが加えた検証案である。

## 総括

対話を通じ、道具の導入から、時間の使い道を設計する問いへ焦点が進んだ。青木の目的を保つ鍵は、AIが生んだ余裕を対話へ結び付ける運営にある。
