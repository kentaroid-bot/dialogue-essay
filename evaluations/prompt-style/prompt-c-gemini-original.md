# 対話から育てる論考生成プロンプト（ハイブリッド型汎用テンプレート）

本テンプレートは、人間（HI）とAIの対話ログから、双方の役割分担と帰属の透明性を保ちつつ、洗練されたストーリー性のある論考を自動生成するための汎用プロンプトです。

---

## 汎用プロンプト（コピーして使用）

```markdown
# 対話から育てる論考（ハイブリッド版仕様）

## 1. 目的（Goal）
人間（{{HUMAN_NAME}}）とAI（{{AI_NAME}}）の対話から、着想が深まり新しい理解へ至るプロセスを、洗練された一つの論考に仕上げてください。
読者が「得られた知見」と「思考が深まった対話のプロセス」の両方を快適に追体験できる文章を目指します。

## 2. 対象データ（Input Data）
以下の対話テキストを元に作成してください。
---
{{DIALOGUE_DATA}}
---

## 3. 基本構成と役割分担（Workflow）
全体は「問い → 人間の着想 → AIの検討 → 到達点」のフローで構成します。

1. **導入**
   - 読者を引き込む「問い」から始め、人間とAIの対話に基づく論考であることを自然な文章で伝えます。
2. **前段：人間の思考（HI）**
   - {{HUMAN_NAME}}の考えを中心に、筋道の通った見解として展開します。
   - 問い返し、思考の修正、方向性の転換（対話の転機）も重要な貢献として自然に織り込みます。
3. **後段：AIの検討（{{AI_NAME}}）**
   - あなた自身の評価・論拠・検証提案を示します。着想の可能性を掘り下げ、仮説の課題や必要な成立条件を具体化します。
4. **総括**
   - 出発点から理解がどう進んだか整理し、次に考える価値のある問いへ着地します。

## 4. スタイルと表現（Style & Output Quality）
- **見出し**: 内容の本質を誠実に伝える自然な言葉にします。
- **視認性と文脈**: 帰属（誰の考えか）は節の冒頭や段落の切り替わりにまとめ、本文の自然な流れを優先します。
- **トーン**: 誠実で思索的な文脈をつくり、必要に応じて読者に語りかける洗練された語り口を採用します。

---

## 5. 絶対遵守事項（Guardrails）
※以下の制約のみ、厳格に遵守してください。
- **原文の改変禁止**: 人間の主張、価値判断、確信の強さを勝手に変更したり、発言していない根拠を補筆しないでください。
- **帰属の厳守**: AIが新たに追加した推論や提案は、必ずAI側の意見として記述し、人間の着想と明確に区別してください。
```

---

## 使い方・カスタマイズガイド

1. **プレースホルダーの置換**
   - `{{HUMAN_NAME}}`: 話者の名前や肩書（例：青木、研究者A）
   - `{{AI_NAME}}`: 使用したAIの名称や役割（例：Codex、アシスタント）
   - `{{DIALOGUE_DATA}}`: 実際の対話ログ（文字起こしやチャット履歴）

2. **変形のポイント**
   - **対話の「転機」を重視する場合**: 3章1節の「前段」にて「どのような問い直しや軌道修正があったか」の記述を強める指定を追加してください。
   - **アイデア検証を重視する場合**: 3章3節の「後段」にて「仮説に対する具体的な検証ステップや指標（KPI）を必ず含める」といった指示を追加してください。
