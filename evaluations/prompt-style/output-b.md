# 生まれた時間を、誰のために使うか

図書館の効率化は、来館者との対話を豊かにできるだろうか。青木とAIの対話から、その可能性を考える。青木の着想をAIが編集し、続いてCodexが検討を加えた。

## 青木が増やしたい時間

AIが本の候補を用意すれば、司書は来館者と話す時間を増やせる。これが青木の出発点だった。履歴だけでは似た本が並びそうだから、その人の今の気分を聞く仕事は司書に残したい。

AIが会話の代替まで提案したとき、青木は「私は人と話す時間を増やしたい」と問いの中心を戻した。そこでAIは、候補を司書が会話から選び直す案を提示した。青木はこれを受け入れ、余った時間が別の業務で埋まる可能性を踏まえて、対話の時間を先に確保する考えへ進んだ。

## Codexの検討：時間を生む道具と、時間を守る運用

私がこの着想に見いだすのは、作業の短縮と、その時間を何に使うかを一緒に設計する視点である。対話の枠を予定に組み込めば、AIの役割も、その枠を支える候補づくりとして位置づけられる。

試行では、候補作成の時間、実際に話せた時間、選書への納得感を併せて記録する方法を提案したい。青木の案はまだ実施されておらず、この比較によって道具と運用の組み合わせを確かめられる。

## 対話が進めた問い

青木の問い返しによって、検討は司書との会話を増やす目的に戻った。その先に現れたのは、短縮できる時間の量に加えて、生まれた時間の使い道を決めるという課題だった。
