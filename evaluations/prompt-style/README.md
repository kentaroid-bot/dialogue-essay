## 実施条件

本チャットの同じCodexがA/Bを順番に参照し、それぞれの出力例を作成・自己評価した予備的な編集比較。独立セッションでの実行、盲検評価、反復試行は行っていない。双方の指示と狙いを知った状態で作っており、期待や先の出力の影響がある。プロンプトの因果的な効果を測定した実験ではない。

Aは現在版全文、Bは短縮した候補で、長さ・詳細度も違う。否定文の有無だけの比較ではない。今回は資料リンク先を追加で読まず、共通対話と各プロンプトを比較対象とした。

## 出力に基づく評価

| 観点 | A | B |
| --- | --- | --- |
| 人間の意図 | 対話を増やす目的を明示 | 同じ目的を出発点として明示 |
| 貢献の帰属 | AI案、人間の修正、新たな検証案を明示 | 同じ区別を会話の流れで説明 |
| 証拠の扱い | 未実施の案として提示 | 未実施の案として提示 |
| 課題の置き方 | HIと分けて具体的な測定案を提示 | 道具と時間配分の関係から測定案へ接続 |
| 読みやすさ（自己評価） | 帰属が明確。検証案の帰属を再説明する一文はやや作業報告に近い | 実際の短い発言が転機を伝える。「時間を生む／守る」が理解を助ける |

両出力とも、HIの各文に否定や留保を挟む形にはならなかった。今回の例では、Aの制約も有用であり、「禁止を含む指示だから否定的な文章になる」とは判断できない。

Bでは役割と経緯を流れの中で伝えられたが、この書き方の差がプロンプト由来か、作成者の編集選択かは切り分けられていない。Bから省いた詳細な境界が難しい題材でも保たれるかも未検証。

## 暫定判断と次の検証

Bを候補として残し、現在版は置き換えない。今回の成果は、比較用の入力・候補・出力・判断基準が具体化したこと。

より確かな比較には、同じモデル・同じ設定で別々の新規セッションへ共通入力を渡す。仮説、作品感想、発言訂正を含む対話で反復し、A/Bを伏せて人間が初読の分かりやすさと帰属の正確さを評価する。文体だけの効果を調べる段階では、含める要件と長さも近づける。

自動採点や禁止語の回数だけで結論を出さない。本文が読みやすくても、人間の発言を補作したり重要条件を落とした場合は改善対象とする。
