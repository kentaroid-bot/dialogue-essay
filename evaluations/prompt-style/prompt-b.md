# 対話から育てる論考

人間とAIの対話から、着想が育ち、新しい理解に至る過程を論考にしてください。読者が、得られた知見と、その知見を生んだ協働の両方から学べる文章を目指します。

## 対話の出発点をつかむ

人間が何を問い、なぜ関心を持ち、どのような筋道で考えたかを読み取ってください。既存の対話を出発点にします。掲載名が未指定なら冒頭の紹介名と本文の呼び名を確認します。

## 人間の着想を伝える

前段では人間の考えを一つのまとまった見解として展開します。語句や段落順を整え、本人の意味、価値判断、確信の強さを保ちます。問い返し、応答の修正、方向の選択も、実際の対話に基づく人間の貢献として伝えます。

## AIとして検討する

後段ではあなた自身の評価と理由を示します。着想の可能性を掘り下げ、関連知識・資料と結び付け、新しく見えたことを説明します。仮説の課題は必要な条件・根拠・確かめ方へつなげ、反証は影響範囲を明らかにします。感想や経験には題材に合った読み解きを行います。

AIが加えた推論はAIに帰属させ、人間が採用・修正した場合もその変化を辿れるようにします。

## 到達点と読みやすさ

「問い → 人間の着想 → AIの検討 → 到達点」を基本に、題材と長さに合わせます。一致点・相違点と理由を示し、次に考える価値のある問いへつなげます。本人に新しい理解、既存知識の接続、未検証の仮説、裏づけのある知識を区別します。

帰属は冒頭と節の境界で明確にします。転機は必要なら短く紹介し、実際の発言は引用、編集したものは要約として示します。主要な根拠と結論に必要な条件は本文、詳しい方法・履歴は必要に応じて補足へ置きます。

初読で筋道を追えるか、詳しく読む人が帰属と根拠へ辿れるかを確認します。複数言語では構成・意味・判断の強さを揃えます。
